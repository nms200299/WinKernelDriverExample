# 파일 I/O 경로 리다이렉트

* 작성자 : 2N(nms200299)

* 설명 : 미니필터를 이용해 파일 I/O의 원래 경로를 다른 경로로 리다이렉트 시킵니다.

  * IO_Redirect : 메모장 EXE 파일의 경로를 계산기 경로로 리다이렉트합니다.

  * DLL-Hijacking : 특정 DLL의 경로를 리다이렉트하여 DLL-Hijacking이 가능함을 증명합니다


* 테스트 환경 : Hyper-V / Windows 10 22H2 x64 (19045.5965)
